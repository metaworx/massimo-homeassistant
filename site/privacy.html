Privacy policy

For Massimo for Home Assistant: the integration and this website. As of 14 November 2026.

In short

The integration runs in your own Home Assistant and talks only to your own Massimo server. It sends nothing to us. This website sets no cookies, runs no scripts and uses no analytics.

Who is responsible

Martin Rüegg, metaworx: massimo@metaworx.ch.

The integration

The integration connects to the Massimo server you set it up with, using the API key you give it, and keeps that address and key in Home Assistant's configuration on your own computer. The week programme card loads Massimo's editor and its texts from that same server, through Home Assistant. Nothing goes to us: no telemetry, no usage statistics, no crash reports. Massimo's own policy is at massimo.metaworx.ch/privacy.html.

This website

ha.massimo.metaworx.ch is hosted on GitHub Pages. GitHub records the IP address of every visit for security and operation; the GitHub General Privacy Statement applies. We see no data about its visitors. The releases and the git branches are downloaded from GitHub as well.

Writing to us

If you write to us, by e-mail or in a GitHub issue, we keep your message and your address to answer it. We delete an e-mail once it is no longer needed; a GitHub issue is public.

Your rights

You may ask us what we hold about you and have it corrected or deleted, at the address above. You may also complain to the data protection authority where you live.

Changes

A change to this policy is published on this page, with its date at the top; its history is in the repository.

Kurz gesagt

Die Integration läuft in Ihrem eigenen Home Assistant und spricht nur mit Ihrem eigenen Massimo-Server. Sie sendet uns nichts. Diese Website setzt keine Cookies, führt keine Skripte aus und verwendet keine Analyse.

Verantwortlich

Martin Rüegg, metaworx: massimo@metaworx.ch.

Die Integration

Die Integration verbindet sich mit dem Massimo-Server, mit dem Sie sie einrichten, mit dem API-Schlüssel, den Sie ihr geben, und speichert diese Adresse und den Schlüssel in der Konfiguration von Home Assistant auf Ihrem eigenen Rechner. Die Wochenprogramm-Karte lädt Massimos Editor und seine Texte von demselben Server, über Home Assistant. Nichts geht an uns: keine Telemetrie, keine Nutzungsstatistik, keine Absturzberichte. Massimos eigene Erklärung steht unter massimo.metaworx.ch/privacy.html.

Diese Website

ha.massimo.metaworx.ch wird von GitHub Pages bereitgestellt. GitHub erfasst bei jedem Aufruf die IP-Adresse, für Sicherheit und Betrieb; es gilt das GitHub General Privacy Statement. Wir sehen keine Daten über ihre Besucher. Auch die Versionen und die Git-Zweige werden von GitHub heruntergeladen.

Wenn Sie uns schreiben

Wenn Sie uns schreiben, per E-Mail oder in einem GitHub-Issue, bewahren wir Ihre Nachricht und Ihre Adresse auf, um zu antworten. Eine E-Mail löschen wir, sobald sie nicht mehr gebraucht wird; ein GitHub-Issue ist öffentlich.

Ihre Rechte

Sie können unter der obigen Adresse erfragen, was wir über Sie gespeichert haben, und es berichtigen oder löschen lassen. Sie können sich auch bei der Datenschutzbehörde Ihres Wohnorts beschweren.

Änderungen
