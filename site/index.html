Massimo for Home Assistant

A Home Assistant integration for Massimo, the server that holds eQ-3 MAX! Cubes: their devices, each room's heating with boost and vacation, and a card that edits a room's week programme with Massimo's own editor.

Massimo keeps the Cubes, their radio budget, pairing and week programmes; Home Assistant becomes one more client of its HTTP API, signed in with an API key of the role integration. It needs Home Assistant 2026.10 or newer and a Massimo server that lists vwt among its features. What it does: the README.

Channels

Every version below 1.0.0 is a pre-release: on the channel beta, or alpha where it carries -alpha. A channel also takes every release of a more stable one that is newer than what it holds. devel is main once its tests have passed, and has no release of its own.

Install with git

Each channel is a branch, distro/<channel>, whose root is the integration's folder. In Home Assistant's configuration folder:

git clone -b distro/beta https://github.com/metaworx/massimo-homeassistant.git custom_components/massimo

Then restart Home Assistant and add the integration under Settings → Devices & services. git -C custom_components/massimo pull and a restart install the channel's next version.

Install a zip

Each channel's newest version is also a zip, /distro/<channel>.zip above, with its signature. Unpack it into custom_components/massimo in Home Assistant's configuration folder, then restart Home Assistant. A tagged release carries the same zip on the releases page.

Check what you install

Two keys sign: the release key every tagged release and the branches distro/stable, beta and alpha, the rolling key distro/devel. Both are in allowed_signers, which the repository carries as keys/allowed_signers. A zip:

ssh-keygen -Y verify -f allowed_signers -I release@ha.massimo.metaworx.ch -n file -s beta.zip.sig < beta.zip

(rolling@ha.massimo.metaworx.ch for devel.) A branch, in the clone:

git -c gpg.ssh.allowedSignersFile=/path/to/allowed_signers verify-commit HEAD

A key is only as trustworthy as the place it came from: take allowed_signers from the repository on GitHub, not from a copy elsewhere. Every tagged release's zip also carries GitHub's build provenance: gh attestation verify massimo.zip -R metaworx/massimo-homeassistant.

Home Assistant's Marketplace and HACS

Once released, the integration is installed from the Marketplace (Home Assistant 2026.11) or HACS (2026.10) by adding this repository by its link. Below 1.0.0 every release is a pre-release: turn on Pre-release for it, or the Marketplace installs the newest commit of main, which no test has to have passed.
